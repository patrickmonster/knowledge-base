# 할 일 보드

프로젝트의 가벼운 할 일을 칸반 보드로 관리한다. 웹 콘솔 **할 일 보드** 화면과 MCP 도구가 같은 데이터(`todos` 테이블, `migrations/025_todos.sql`)를 쓴다.

## 화면

- 열: 상태 — 시작 전(`not_started`), 진행 중(`in_progress`), 완료(`completed`), 아이디어(`idea`). 머리에 건수 표시.
- 행: 우선순위 — 높음(`high`), 보통(`medium`), 낮음(`low`). 행 머리를 눌러 접고 펼친다(브라우저에 기억).
- 카드: 제목, 상태, 분류, 완료 체크, 진행률 막대(설정한 경우), 담당자·마감일(지난 마감은 빨간색).
- 카드를 끌어 다른 칸이나 다른 카드 앞에 놓으면 `move_todo`로 저장된다. 키보드 사용자는 카드에서 Enter로 수정 창을 열어 상태·우선순위를 바꾼다.
- 완료 체크는 완료 열로, 해제는 진행 중 열로 옮긴다. 진행률이 있는 카드를 완료로 옮기면 100%가 된다.
- 칸의 “새로 만들기”는 그 칸의 상태·우선순위로 새 할 일 창을 연다.
- 필터: 분류, 내게 배정된 것만. 한 번에 최대 500건 표시.

## 권한

- 조회: 프로젝트 참여자 모두(조회자 포함, 수정 창은 읽기 전용).
- 추가·수정·이동·삭제: 편집자·관리자·소유자. 읽기 전용 MCP 키는 거부된다.
- 담당자는 활성 상태의 프로젝트 참여자만 지정할 수 있다.
- 프로젝트당 최대 5000건.

## MCP 도구

| 도구 | 설명 |
| --- | --- |
| `list_todos` | 보드 순서(우선순위 → 상태 → 위치)로 목록. `status`, `priority`, `category`, `assignee_id`, `mine`, `limit`(최대 500) |
| `save_todo` | `todo_id` 없이 추가(칸 맨 끝). 수정은 `todo_id`와 `expected_revision`, 모든 필드를 바꾸므로 유지할 값도 보낸다(생략한 `progress`·`assignee_id`·`due_date`는 지워짐). 상태·우선순위가 바뀌면 새 칸 맨 끝으로 간다 |
| `move_todo` | `status`·`priority` 칸으로 옮기고 `before_id` 앞(생략 시 맨 끝)에 놓는다 |
| `delete_todo` | 영구 삭제 |

## 정렬 위치

칸 안 순서는 `position`(오름차순)이다. 새 카드는 칸의 최댓값 + 1024, 카드 사이에 놓으면 앞뒤의 중간값을 쓴다. 간격이 1e-6 이하로 줄면 그 칸을 1024 간격으로 다시 매긴다. 동시에 같은 칸에 놓는 요청이 같은 간격을 고르지 않도록 이동은 프로젝트 단위 advisory lock 안에서 처리한다.

## 감사 기록

`todo_id`, `status`, `priority`, `category`, `before_id`만 감사 입력으로 남기고 제목·내용은 복사하지 않는다.
