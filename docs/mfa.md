# 2단계 인증(MFA)

웹 로그인에 인증 앱의 시간 기반 일회용 코드(TOTP, RFC 6238)를 추가합니다. 사용자가 **내 계정** 화면에서 직접 켜고 끕니다. 아직 팀 전체에 강제하지는 않습니다.

## 서버 설정

- `MFA_ENCRYPTION_KEY`: 32자 이상의 무작위 문자열. 사용자별 TOTP 비밀키를 AES-GCM으로 암호화하는 데 씁니다. 예: `openssl rand -base64 48`.
- 값이 없으면 MFA를 새로 켤 수 없습니다(`MFA_UNAVAILABLE`, 503). 이미 MFA를 켠 사용자는 로그인이 실패합니다(fail closed).
- **값을 바꾸거나 잃어버리면 기존 사용자의 MFA를 풀 수 없습니다.** 관리자가 해당 사용자의 MFA를 초기화하고 사용자가 다시 등록해야 합니다. 값은 Railway 변수에만 두고 Git·문서·지식베이스에 쓰지 않습니다.
- 마이그레이션 `016_mfa.sql`: `user_mfa`(암호화한 비밀키, 활성 시각, 마지막 사용 시간 단계), `mfa_recovery_codes`(해시), `mfa_challenges`(비밀번호 확인 후 대기 중인 로그인). `users` 표에는 MFA 정보를 두지 않습니다.

## 사용 흐름

1. **설정 시작**(`POST /api/mfa/setup`): 새 비밀키와 `otpauth://` 링크를 발급합니다. 인증 앱에 “설정 키 입력”으로 등록합니다. QR 코드는 아직 표시하지 않습니다.
2. **켜기**(`POST /api/mfa/enable`): 현재 비밀번호와 앱의 6자리 코드를 15분 안에 입력합니다. 복구 코드 10개가 한 번만 표시되고, 지금 브라우저를 뺀 다른 로그인 세션은 종료됩니다.
3. **로그인**: 비밀번호가 맞으면 세션 대신 5분짜리 확인 단계(`kb_mfa` 쿠키, HttpOnly·SameSite=Strict, 경로 `/api/login/mfa`)가 열립니다. `POST /api/login/mfa`에 앱 코드나 복구 코드를 보내면 세션이 발급됩니다.
4. **복구 코드 다시 만들기**(`POST /api/mfa/recovery-codes`): 앱 코드가 필요합니다. 기존 복구 코드는 모두 무효가 됩니다.
5. **끄기**(`POST /api/mfa/disable`): 현재 비밀번호와 앱 코드 또는 복구 코드가 필요합니다.
6. **관리자 초기화**(`POST /api/admin/users/mfa-reset`, 전역 관리자, 웹 **사용자 관리**): 기기를 잃은 사용자의 MFA를 지우고 그 사용자의 로그인 세션을 종료합니다. 자기 자신은 초기화할 수 없습니다.

## 보안 규칙

- 코드: 6자리, 30초, 앞뒤 한 단계(±30초) 허용. 이미 쓴 시간 단계 이하의 코드는 거부합니다(재사용 방지).
- 복구 코드: 10자(`abcde-fghjk` 형태), 대소문자·하이픈 무시, 각 1회. SHA-256 해시로만 저장합니다.
- 시도 제한: 확인 단계당 5회, 사용자당 15분 10회, IP당 15분 50회. MFA 설정 변경(비밀번호 확인 포함)은 사용자당 15분 10회.
- 비밀번호가 바뀌면(변경·재설정) 대기 중인 확인 단계는 무효가 됩니다. 비밀번호 재설정 링크는 MFA를 끄지 않습니다.
- **MCP 키는 MFA의 영향을 받지 않습니다.** 키는 로그인한 웹 세션에서만 발급되므로 MFA가 발급을 보호하고, 이미 발급한 키는 그대로 동작합니다. 관리자 초기화도 키를 폐기하지 않습니다.
- 감사 로그: `mfa_setup`, `mfa_enable`, `mfa_disable`, `mfa_recovery_codes`, `mfa_reset`, `view_mfa`, 비밀번호 확인 후 `login_password`(details `mfa: required`), 두 번째 단계 실패 `login_mfa`, 성공 `login`(details `mfa: totp|recovery_code`). 비밀키·코드·복구 코드는 기록하지 않습니다. 운영 현황의 로그인 실패 수에 `login_mfa` 실패가 포함됩니다.

## 아직 없는 것

- 팀 전체 또는 관리자에게 MFA 강제
- QR 코드 표시(현재는 설정 키·otpauth 링크 복사)
- WebAuthn(패스키·보안 키), SSO, OAuth 전용 MCP 클라이언트
