# Google OTP(Google Authenticator)로 2단계 인증 설정하기

웹 콘솔 로그인에 Google OTP 앱(Google Authenticator)의 6자리 코드를 추가하는 방법입니다. 서버 동작과 보안 규칙은 [2단계 인증(MFA)](mfa.md)을 참고하세요.

- 2단계 인증은 사용자가 **내 계정**에서 직접 켭니다. 팀 전체에 강제하지 않습니다.
- MCP 접속 키는 영향을 받지 않습니다. 이미 발급한 키는 그대로 동작합니다.
- 아직 QR 코드는 표시하지 않습니다. 앱에 **설정 키를 직접 입력**해서 등록합니다.

## 준비

1. 휴대폰에 Google OTP 앱을 설치합니다.
   - Android: Play 스토어에서 "Google Authenticator"
   - iPhone: App Store에서 "Google Authenticator"
2. 휴대폰 시간이 **자동(네트워크 제공 시간)** 으로 설정돼 있는지 확인합니다. 코드는 30초마다 바뀌며 서버는 앞뒤 30초까지만 허용하므로, 시간이 1분 이상 어긋나면 코드가 맞지 않습니다.
3. 웹 콘솔에 로그인하고 왼쪽 메뉴 **내 계정**을 엽니다.

**2단계 인증 (OTP)** 카드에 "이 서버에는 MFA_ENCRYPTION_KEY가 설정되지 않아 아직 사용할 수 없습니다"라고 나오면 서버 관리자가 먼저 설정해야 합니다(아래 [관리자용](#관리자용)).

## 1. 설정 시작

1. **내 계정 → 2단계 인증 (OTP) → 설정 시작**을 누릅니다.
2. 4자씩 띄어 쓴 **설정 키**가 나옵니다. **설정 키 복사**를 누르거나 직접 받아 적습니다.
3. 이 화면을 연 뒤 **15분 안에** 아래 2·3단계를 마쳐야 합니다. 시간이 지나면 **설정 시작**을 다시 누릅니다(이전 키는 버립니다).

> 설정 키는 비밀번호와 같습니다. 채팅·메일·문서에 붙여 넣지 말고, 화면 캡처를 남기지 마세요.

## 2. Google OTP 앱에 등록

1. 앱을 열고 오른쪽 아래 **+** 를 누릅니다.
2. **설정 키 입력**(영문: *Enter a setup key*)을 고릅니다. **QR 코드 스캔**은 쓰지 않습니다.
3. 다음과 같이 입력합니다.

   | 항목 | 입력 값 |
   | --- | --- |
   | 계정 | `Knowledge Base` 또는 로그인 이메일 등 알아보기 쉬운 이름 |
   | 키 | 웹 화면의 설정 키(띄어쓰기는 있어도 없어도 됩니다) |
   | 키 유형 | **시간 기준**(*Time based*) |

4. **추가**를 누르면 6자리 코드가 30초마다 바뀌며 표시됩니다.

PC에서 복사한 키를 휴대폰으로 옮기기 어렵다면 키를 보고 직접 입력하세요. 대문자와 숫자 2~7로만 이루어져 있어 헷갈리는 문자(0·1·8)가 없습니다.

### otpauth 링크

화면의 **otpauth 링크** 항목은 링크로 등록할 수 있는 비밀번호 관리자(1Password 등)용입니다. Google OTP 앱에는 설정 키 입력을 권장합니다. 링크를 QR 코드로 바꾸려고 **온라인 QR 생성 사이트에 붙여 넣지 마세요.** 링크에 설정 키가 그대로 들어 있습니다.

## 3. 2단계 인증 켜기

1. 웹 화면으로 돌아와 **인증 앱의 6자리 코드**에 앱에 보이는 코드를 입력합니다.
2. **현재 비밀번호**를 입력하고 **2단계 인증 켜기**를 누릅니다.
3. **복구 코드 10개**가 한 번만 표시됩니다(`abcde-fghjk` 형태). 비밀번호 관리자 등 휴대폰과 **다른 곳**에 저장하세요. 이 화면을 닫으면 다시 볼 수 없습니다.
4. 켜는 순간 지금 브라우저를 뺀 다른 로그인 세션은 모두 로그아웃됩니다.

코드가 틀렸다고 나오면 앱의 코드가 바뀐 직후 새 코드로 다시 입력해 보세요. 계속 실패하면 휴대폰 시간 설정을 확인합니다.

## 로그인하기

1. 이메일과 비밀번호로 로그인합니다.
2. **2단계 인증** 화면이 나오면 Google OTP 앱의 6자리 코드를 입력합니다. 이 화면은 5분 동안 유효하고 5번까지 시도할 수 있습니다. 넘으면 비밀번호부터 다시 입력합니다.
3. 휴대폰이 없을 때는 **복구 코드 사용**을 누르고 복구 코드 하나를 입력합니다. 쓴 복구 코드는 다시 쓸 수 없습니다.

같은 코드는 한 번만 쓸 수 있습니다. 방금 로그인에 쓴 코드로 바로 다시 로그인하려면 다음 코드가 나올 때까지(최대 30초) 기다립니다.

## 휴대폰을 바꿀 때

새 휴대폰으로 옮기는 방법은 세 가지입니다. 위에서부터 권장합니다.

1. **2단계 인증을 다시 등록**: 기존 휴대폰으로 로그인한 상태에서 **2단계 인증 끄기**(비밀번호 + 앱 코드)를 누르고, 새 휴대폰으로 [1. 설정 시작](#1-설정-시작)부터 다시 합니다. 새 설정 키와 새 복구 코드가 생깁니다. 기존 휴대폰 앱의 항목은 삭제합니다.
2. **Google OTP 앱의 계정 이전 기능**: 기존 휴대폰 앱의 메뉴에서 계정 이전(내보내기)을 골라 새 휴대폰으로 스캔합니다. 설정 키가 그대로 옮겨지므로 서버 쪽에서는 할 일이 없습니다.
3. **Google 계정 동기화**: 앱에 Google 계정으로 로그인해 두면 새 휴대폰에서 같은 Google 계정으로 로그인했을 때 코드가 복원됩니다. 편리하지만 설정 키가 Google 계정에 백업되므로, 그 Google 계정의 보안(2단계 인증 등)도 함께 관리해야 합니다.

## 휴대폰을 잃어버렸을 때

- **복구 코드가 있으면**: 로그인 화면에서 **복구 코드 사용**으로 로그인한 뒤, **내 계정**에서 **2단계 인증 끄기**(비밀번호 + 복구 코드)를 하고 새 휴대폰으로 다시 등록합니다.
- **복구 코드도 없으면**: 전역 관리자에게 초기화를 요청합니다. 초기화되면 기존 로그인 세션이 종료되고 다음 로그인은 비밀번호만으로 됩니다. 로그인한 뒤 다시 등록하세요. MCP 키는 유지됩니다.

## 복구 코드 관리

- **내 계정**의 2단계 인증 카드에 남은 복구 코드 개수가 표시됩니다. 3개 이하가 되면 안내가 나옵니다.
- **복구 코드 다시 만들기**에 앱 코드를 입력하면 새 복구 코드 10개가 나오고 기존 코드는 모두 쓸 수 없게 됩니다.

## 자주 묻는 질문

| 증상 | 확인할 것 |
| --- | --- |
| 코드가 계속 틀리다고 나옴 | 휴대폰 시간이 자동인지, 앱에 등록한 키가 지금 서버 화면의 키와 같은지(설정을 다시 시작했다면 이전 항목은 지우고 새 키로 등록) |
| 시도 횟수 제한 오류 | 확인 화면당 5회, 사용자당 15분 10회로 제한됩니다. 잠시 뒤 다시 시도합니다 |
| 설정 화면에서 키가 사라짐 | 15분이 지났거나 화면을 새로 고쳤습니다. **설정 시작**을 다시 누릅니다 |
| 2단계 인증을 켰는데 로그인이 안 됨 | 서버 설정이 바뀌었을 수 있습니다. 복구 코드로도 안 되면 관리자에게 초기화를 요청합니다 |
| 비밀번호를 재설정함 | 비밀번호 재설정은 2단계 인증을 끄지 않습니다. 새 비밀번호와 앱 코드로 로그인합니다 |

## 관리자용

- 서버에 `MFA_ENCRYPTION_KEY`(32자 이상 무작위 문자열, 예: `openssl rand -base64 48`)가 있어야 사용자가 2단계 인증을 켤 수 있습니다. 값은 Railway 변수에만 둡니다. **값을 바꾸거나 잃으면** 등록한 모든 사용자의 2단계 인증을 초기화해야 합니다. 자세한 내용은 [2단계 인증(MFA)](mfa.md#서버-설정).
- 사용자 초기화: **사용자 관리**에서 해당 사용자의 **2단계 인증 초기화**를 누릅니다. 전역 관리자만 할 수 있고, 자기 자신은 초기화할 수 없습니다. 전역 관리자가 한 명뿐이면 본인의 복구 코드를 반드시 보관하세요.
